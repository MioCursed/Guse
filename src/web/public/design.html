SISTEMA DE DESIGN

Guia visual

Uma linguagem de sala calma, legível e consistente: palco central para vídeo, presença lateral para participantes e controles agrupados por tarefa.

TOKENS

Cor, espaçamento e forma

Os tokens vivem em style.css. A paleta escura é o padrão para reduzir distração em conteúdo de vídeo; a paleta clara é escolhida pelo controle de tema.

  • Grade: unidade base 8 px; 4 px para ajustes menores.
  • Raios: 12 px para controles, 20 px para cartões, 28 px para destaques.
  • Tipografia: pilha nativa do sistema; títulos compactos, texto de ajuda em altura de linha confortável.
  • Elevação: sombras suaves; contraste e bordas continuam distinguindo cartões sem depender só de sombra.

COMPONENTES

Estados e controles

Conectado · boa qualidade 3 pessoas

Foco de teclado visível, alvos interativos com pelo menos 44 px, mensagens de conexão em região viva e preferência por movimento reduzido respeitada. O layout passa do palco com painel lateral para uma coluna em telas estreitas.

REFERÊNCIAS

Princípios de interface

  • Material Design 3: hierarquia, tokens e componentes coerentes.
  • Apple Human Interface Guidelines: controles familiares e comportamento consistente.
  • WCAG 2.2: foco, contraste, teclado e alvos de interação.
  • Nielsen Norman Group: estado visível, controle do usuário e recuperação de erros.
Este guia descreve a intenção do sistema visual; conformidade WCAG ainda exige auditoria automatizada e testes com pessoas.
